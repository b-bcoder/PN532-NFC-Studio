# Changelog

Notable changes to PN532 NFC Studio are documented here.

## Unreleased

v1.0.0

### Added

- Show a button for each unique, valid HTTP(S) URL/URI record read from an NDEF
  tag, allowing it to be opened in the default browser.
- Use **F11** to switch between borderless fullscreen and windowed mode.

### Changed

- Removed the Electron application menu bar.
